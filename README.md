# 📘 Semana 7 - Estructuras de repetición en Java

Repositorio con los ejercicios en **Java** de la **Semana 7**, enfocados en las estructuras de repetición (`for`, `while`, `do-while`), el uso de contadores y acumuladores, la validación de datos y los ciclos anidados.

## 📂 Contenido

| Archivo | Descripción |
|---------|-------------|
| `EstructuraRepeticion.java` | Introducción a las estructuras de repetición |
| `for,while,do-while.java` | Comparación de los tres tipos de ciclos |
| `contadores y acumuladores.java` | Uso de contadores y acumuladores dentro de ciclos |
| `TrazaSuma.java` | Prueba de escritorio (traza) de una suma con ciclo |
| `SeriesNumericas.java` | Generación y cálculo de series numéricas |
| `TablasMultiplicar.java` | Tablas de multiplicar con ciclos |
| `ciclos anidados.java` | Ciclos dentro de otros ciclos |
| `CicloInfinito.java` | Ejemplo de ciclo infinito y cómo evitarlo |
| `casosLimite.java` | Pruebas con valores límite en los ciclos |
| `validaciónEdad.java` | Validación de una edad ingresada por el usuario |
| `validacion+contador+acumulador.java` | Validación de datos combinada con contador y acumulador |
| `CafeteriaUniversitaria.java` | Ejercicio aplicado: caso de una cafetería universitaria |
